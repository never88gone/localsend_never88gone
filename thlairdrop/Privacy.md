# 糖葫芦投送 (THLAirDrop / LocalSend) 隐私政策

**最近更新日期**：2026年5月18日

欢迎使用由 **武汉铭研信息技术有限公司** 开发的局域网文件传输工具 **THLAirDrop**（以下简称“本应用”）。我们非常重视您的个人隐私保护，本隐私政策旨在向您清晰地说明我们如何处理数据，以及我们对保护您隐私的庄严承诺。

---

> [!IMPORTANT]
> ### 🔒 核心声明：本应用无任何云端服务器
> **本应用属于纯本地局域网（LAN）点对点（P2P）文件与消息传输效率工具，没有任何云端后台服务器！**
> * **数据不上云**：所有文件、图片、视频及文本消息的传输，都是直接在您自己的局域网内设备之间进行高速直连传输，不经过任何外部服务器。
> * **无法收集隐私**：由于本应用不提供且不运行任何云端云存储或中转服务器，开发者以及任何第三方都**绝对无法收集、存储或调阅**您的任何文件内容、传输历史、设备别名或局域网 IP 地址。您的隐私数据永远只保留在您自己的设备中。

---

## 一、 我们如何处理您的信息

为了向您提供核心的局域网点对点文件传输服务，我们仅在应用运行期间，基于本地局域网通信的技术需要，临时在设备本地内存中处理以下信息。**这些信息绝不会发送到局域网外部的互联网：**

### 1. 设备发现与识别信息
* **设备别名**：为了在局域网内向其他发送/接收设备直观展示您的身份，应用需要获取或由您自定义生成一个设备别名。该别名仅用于局域网内的 UDP 广播/组播。
* **本地 IP 地址与传输端口**：应用需要获取本机在当前 Wi-Fi 下的本地临时 IP 地址和端口号（默认 `53317`），用以在设备间建立 TCP/UDP 传输长连接。
* **设备类型与系统版本**：例如系统名称（HarmonyOS），仅用于在局域网中展示对应的设备图标，便于发送方快速识别。

### 2. 文件与消息传输数据
* **待传输文件**：当您主动选择发送图片、视频或文档时，应用会读取该文件并将其转换为高强度加密数据流，直传至局域网接收端。本应用不在本地保存任何传输文件的副本或多余缓存。
* **文本消息**：当您发送文本时，消息直接发送至接收端展示，不涉及云端中转。
* **数据存储**：所有传输的文件均会直接存放在您在设置中指定的本地存储目录中。

## 二、 核心系统权限申请与使用说明

在您使用应用的过程中，我们可能会向您申请以下系统权限。所有权限均有明确的系统提示，您可以在系统设置中随时关闭：

| 权限名称 | 权限说明 | 申请与使用目的 | 是否可选 |
| :--- | :--- | :--- | :--- |
| **访问外部网络**<br>`ohos.permission.INTERNET` | 允许应用访问网络（包括局域网） | 用于建立局域网内设备间的 TCP 传输长连接，实现数据的高速收发。 | **必选**<br>（核心传输功能所必需） |
| **获取WIFI及网络状态**<br>`ohos.permission.GET_WIFI_INFO` | 允许应用获取 Wi-Fi 状态和本地网络状态信息 | 用于获取本机在当前 Wi-Fi 下的局域网 IP 地址，以便局域网内其他设备能够发现并与您直连。 | **必选**<br>（核心发现功能所必需） |
| **本地媒体与文件读写**<br>(系统存储/媒体权限) | 允许应用读取或写入本地文件目录 | 用于读取您主动选择发送的本地文件，以及在接收到外部文件时，将文件保存到您的系统下载区中。 | **必选**<br>（涉及文件收发时） |

## 三、 信息的存储与共享

* **存储期限**：由于我们不使用任何云端服务器，所有收发数据均是即时处理、即时传输。传输完成后，应用本地内存中的传输缓存会被立即清空。传输历史记录保存在您本机的安全沙箱中，您可以随时手动清除。
* **第三方共享**：我们**不与任何第三方共享、转让或披露**您的个人信息或传输数据。本应用不集成任何第三方广告 SDK 或商业追踪分析探针。

---

## 四、 端到端安全保障机制

虽然所有传输都在您的本地局域网进行，但为了防止同一局域网内的第三方恶意监听，我们采用了高强度的安全保护：
* **TLS 端到端加密**：设备每次启动 LocalSend 传输服务时，均会在设备本地自动生成唯一的自签名 TLS 证书。所有数据传输均强制使用 HTTPS 协议，提供高强度的数据链路加密保护。
* **手动确认机制**：默认情况下，任何外部设备向您发送文件或消息时，均需在您的界面上进行手动确认。

## 五、 您的权利

您对自己的个人信息拥有完全的控制权：
1. **修改设备别名与端口**：您可以通过应用内的“设置”页面随时修改别名或更换服务端口。
2. **清除历史记录**：您可以在传输历史页面一键删除所有的传输记录。
3. **撤销权限**：您随时可以在系统的“系统设置 -> 应用管理”中撤销授予本应用的任何权限。
